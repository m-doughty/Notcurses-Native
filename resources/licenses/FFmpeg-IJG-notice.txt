Independent JPEG Group acknowledgement for FFmpeg
=================================================

This software is based in part on the work of the Independent JPEG Group.

That sentence is the acknowledgement the Independent JPEG Group's licence
requires of anyone who distributes executable code derived from its
software: condition (2) of the notice below. The FFmpeg libavcodec
distributed with this software contains such code. FFmpeg's inverse DCT,
libavcodec/jrevdct.c, is taken from the IJG's libjpeg, and it is compiled
into this libavcodec because the JPEG (MJPEG) and MPEG-4 decoders built
into it depend on it. FFmpeg's other two IJG-derived files,
libavcodec/jfdctfst.c and libavcodec/jfdctint_template.c, are forward-DCT
code that only FFmpeg's encoders and filters use; none of those is built
here.

The IJG's notice follows exactly as it appears at the top of
libavcodec/jrevdct.c in FFmpeg n8.1.2 (lines 2-37), with only the C
comment markers removed.
